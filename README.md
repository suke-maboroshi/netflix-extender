# Netflix Extender

Netflix Extender is a personal, non-commercial Google Chrome extension designed to improve the Netflix browsing experience.

## Features

- Enhanced browsing and My List management
- Custom filtering and sorting of saved titles
- Personal title bookmarking and organization
- Planned integration of TMDb ratings and external movie/TV identifiers

## TMDb API Usage

The extension is intended to use the TMDb API to identify movies and TV series, retrieve ratings, and obtain external identifiers for additional rating information.

## Project Status

This project is under private development for personal use. The source code is not publicly available.
